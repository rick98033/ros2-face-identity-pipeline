# Security policy

This is an archived project and is not monitored as a supported product.

Do not place face images, embeddings, enrollment stores, credentials, device
identifiers, or deployment details in public issues. Revoke exposed credentials
first and arrange a private reporting channel with the repository owner.

Identity output from this project must not, by itself, authorize an irreversible
or safety-critical action. Downstream systems must enforce their own policy,
freshness, confirmation, and physical-safety checks.
